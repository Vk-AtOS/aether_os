Core Capabilities

CI fails.
DCSP fixes it.

Multi-CI Support

Receives webhooks from GitHub Actions, GitLab CI, and Jenkins. HMAC-SHA256 verified. Parses logs from all three formats into a unified failure model for LLM analysis.

LLM Patch Generation

Routes repair tasks across Anthropic Claude, AWS Bedrock, and OpenRouter with automatic fallback. Generates context-aware diffs by reading the failing code, not just the error message.

Sandbox Validation

Every generated patch runs in an isolated sandbox before it touches your code. If the patch doesn't pass, DCSP escalates to a human rather than applying a broken fix.

Fingerprint Reuse

Learns from every repair. Similar failures get the same fix instantly — no LLM call needed. Fingerprint database grows with every resolved incident, making the system faster over time.

Z3 Formal Verification

Auth invariants, SQL injection safety, and state machine correctness are verified by the Z3 theorem prover before any patch is applied. Mathematical proof, not best-guess testing.

Smart Escalation

When confidence is below threshold, DCSP escalates with a full diagnosis report — root cause, failing test, attempted fixes, and recommended next steps — so your engineer starts with context.

Integration

Connect in
under 5 minutes.

github-actions-integration.yml 
# Option A: Install the GitHub App (zero-config)
→ github.com/apps/dcsp-autofix → Install → Select repo

# Option B: Direct webhook (GitLab CI / Jenkins)
POST https://your-dcsp-instance/webhook/ci/auto

{
  "repo_name": "org/repo",
  "branch":    "main",
  "log_content": "<raw CI log output>"
}

→ DCSP returns: patch_diff, confidence, explanation
→ If confidence > 0.85: patch auto-applied via PR
→ If confidence < 0.85: Slack/email escalation sent
