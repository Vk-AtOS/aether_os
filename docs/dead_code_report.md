## Method

1. Script: `/private/tmp/claude-501/-Users-apple/1a57cd35-efca-4a1e-b634-a519eaf0e507/scratchpad/a_docs/dead_code/graph.py`. It lists every tracked `.py` file (`git ls-files '*.py'`, 1141 files, 909 outside tests), parses each with `ast` (nothing is imported or run), and resolves absolute and relative imports to module files. A parent package `__init__.py` counts as imported when a child is imported.
2. Dynamic use is added as edges: string literals that look like dotted module paths, f-strings such as `f"aether_os.phases.{name}.task_agent"` (every plain word in the same file is tried as `{name}`), and dotted paths or `*.py` paths in `.yml .yaml .json .toml .sh .service .tf .ini .conf Dockerfile*` (comment text is ignored).
3. Roots (non-test only): `main.py`, `seed_db.py`, `gateway/api.py`, `gateway/preview_server.py`, `orchestrator/phase_sequence.py`, everything under `cli/`, `scripts/`, `alembic/`, and any module named in a deploy or config file (uvicorn targets in `Dockerfile:51`, `docker-compose.yml:157`, `deploy/aetheros.service:12`, `deploy/terraform/aws/modules/compute/services.tf:17,50`; `scripts/db_migrate.py` from compose, helm, deploy.sh). 111 roots in total. Tests are never roots.
4. Reachable = a non-test module reachable from a root through non-test importers. Loaders counted as callers: `gateway/api.py:231-320` (router list, every path is a literal in the `_ROUTERS` list), `orchestrator/phase_sequence.py:142` (`PHASE_SUPERVISORS` list, lines 108-121), the stage supervisors (`importlib.import_module(f"aether_os.phases.{phase_name}.task_agent")`, each phase name checked against the lists in `stages/s01..s12/supervisor.py`), `core/domain_knowledge/loader.py:68` (12 pack names), `core/validators/registry.py:28` and `core/repair_learning.py:528` (file loaders for generated validators under `core/validators/auto_generated`, not repo modules).
5. Result: 776 modules reachable, 133 unreachable (17,325 lines). 13 of the 133 are empty or one-line `__init__.py` files of dead packages and are not listed row by row. 120 are listed below.
6. Every listed item was then checked by hand with `git grep` (command and hit count in each row). The "importers do not count" text names the dead importer and why. Velaris check: `grep -rIl aether_os /Users/apple/Desktop/wt2/int/velaris_knackforge --include=*.py --include=*.yml --include=*.toml --include=*.json` returned 0 files, so Velaris imports nothing from this package; every Velaris count is 0 and is not repeated per row.
7. Below module level: `symbols.py` (same folder) lists top-level public functions and classes in reachable modules whose name appears nowhere else in any `.py`, `.yml`, `.yaml`, `.json`, `.toml`, `.html`, `.sh` file, and only once in its own file. 58 found; the 20 with 15 or more lines are listed, and each was re-checked with `git grep -nw`.

### Limits of the method

- Names built at run time in other ways (`getattr(module, name)` on a string from data, plugin entry points in installed third-party packages, strings assembled by concatenation) are not seen. Only the f-string form and literals are.
- The f-string rule is generous: a phase directory is treated as reachable if its name appears as a plain word anywhere in the supervisor file. I confirmed the live phase list by hand against `grep` of each phase name in `stages/` (see "Phase directories" below).
- A route in a mounted router counts as live even if no dashboard page calls it. Unused API wrappers on the dashboard side are KAN-166 and were skipped.
- `pyproject.toml:51` mentions `seed_templates/__init__.py` in a lint config; the script counts that as a root, so it is shown as reachable although nothing imports it. It is handled by hand under "Keep".
- Reachability is by import, not by execution: a reachable module may still have functions nobody calls. Only the symbol sweep above looks at that, and only for names that appear nowhere else.
- Tests that reference an item are listed from `git grep` of the dotted path and from import edges. Tests that load a module by file path are not seen.
