# AetherOS Demo Script

**Format**: Live demo or screen recording — approximately 8 minutes
**Audience**: Technical founders, CTOs, engineering managers, investors
**Goal**: Show that AetherOS generates a real, working application end-to-end from a single sentence

---

## Opening Hook (0:00 – 0:45)

"What if you could describe a business application in plain English and have a fully scaffolded, tested, and deployed codebase ready in under ten minutes — with a live URL?"

"That's AetherOS. I'm going to show you, right now, with a real app. No cherry-picking, no pre-built project — we're starting from scratch."

---

## Step 1 — Log In and Orient (0:45 – 1:30)

Navigate to `https://app.aetheros.ai` (or localhost).

- Point out the dashboard: **Projects**, **Runs**, **Intelligence**, **Health** tabs
- "This is the multi-tenant control plane. Everything you're about to see is scoped to your organisation."

---

## Step 2 — Submit a Requirement (1:30 – 2:30)

Click **New Project** and fill in the form:

| Field | Value |
|-------|-------|
| Project name | `LeadFlow CRM` |
| Requirement | `Build a SaaS CRM with contact management, a deal pipeline with Kanban board, email activity tracking, and role-based access for sales reps and managers.` |
| Domain | `saas` |

Click **Launch**.

**Talking point**: "That's it. One sentence. AetherOS now hands this to p01 — the Intake and Requirements phase — which uses Claude Sonnet 4.6 to parse this into a full structured PRD."

---

## Step 3 — Watch the Pipeline Run (2:30 – 5:00)

The run detail page opens automatically with a live SSE stream. Walk through the phases as they complete:

- **p01 Intake**: "Requirement parsed. Notice the compliance flags — this is a SaaS app so GDPR and SOC2 guardrails are applied."
- **p02 Architecture**: "Entity-relationship diagram generated. Tech stack selected: FastAPI + React + PostgreSQL."
- **p03 Scaffolding**: "Project directory structure created from cookiecutter template."
- **p04 Backend**: "FastAPI routes, SQLAlchemy models, JWT auth — all generated by LLM, then verified by our Truth Engine."
- **p05 Frontend**: "React 18 TypeScript components, TanStack Query data fetching, Tailwind styling."
- **p06 Review and Security**: "Bandit and Semgrep scan the generated code. Any vulnerability is flagged and the pipeline pauses for review."
- **p07 Testing**: "Unit tests, integration tests, Playwright E2E tests — all generated and executed against the code."
- **p08 CI/CD**: "GitHub Actions workflow, Dockerfile, container readiness probe."

**Talking point**: "Each phase has a quality gate. The gate must pass — meeting a confidence threshold — before the next phase begins. If a gate fails, p07b Self-Healing kicks in: it patches the code and re-runs the tests automatically."

---

## Step 4 — View the Generated Code (5:00 – 6:00)

Click **Files** on the completed run.

- Open `src/main.py` in the Monaco editor (in-browser)
- Show `src/models.py` — real SQLAlchemy models for Contact, Deal, Activity
- Open `src/auth.py` — RBAC with sales_rep and manager roles
- Point out the VS Code button: "One click opens this entire project in your local VS Code."

**Talking point**: "This is production-quality code, not a toy scaffold. It has auth, tests, a CI pipeline, and a Dockerfile — everything a real team would write."

---

## Step 5 — Show the Client Portal (6:00 – 7:00)

Click **Client Portal** on the run.

- Show the read-only portal with the generated PRD, architecture diagram, and artifact list
- "Your client gets a URL — no login required — where they can review, comment, and approve. The portal is generated as a standalone deliverable."

---

## Step 6 — Billing and Usage (7:00 – 7:45)

Navigate to **Billing**.

- Show the run cost breakdown: tokens consumed, LLM calls per phase, total cost in USD
- "Every LLM call is tracked. You see exactly what each phase cost. For enterprise customers, we support per-org budget caps."

---

## Closing (7:45 – 8:00)

"Ten minutes ago, we had a sentence. Now we have a deployable SaaS CRM with auth, a Kanban board, email tracking, tests, and a client portal. That's AetherOS."

"Questions on the architecture, the security model, or how to run this on your own infrastructure — happy to dig in."

---

## Key Talking Points (Objection Handling)

| Objection | Response |
|-----------|----------|
| "Is the code actually good?" | Show the Bandit/Semgrep clean scan result and the passing test suite |
| "Can I edit the output?" | Yes — Monaco editor in-browser, or open in VS Code, or clone the generated repo |
| "What LLMs does it use?" | Anthropic Claude Sonnet 4.6 primary; Google Gemini 2.5 Flash secondary; Ollama for air-gapped |
| "Can I self-host?" | Yes — Docker + PostgreSQL + Redis. Full setup in CONTRIBUTING.md |
| "What about compliance?" | GDPR/HIPAA/PCI-DSS/SOC2 guardrails are applied based on domain at intake |
| "How much does a run cost?" | Approximately $0.40 to $1.20 per full pipeline run depending on app complexity |
