# DCSP VS Code Extension

Trigger AI-powered code repairs directly
from VS Code.

## Features
- **Repair Current File**: Send the current
  file to DCSP for analysis and repair
- **Open Dashboard**: Launch the DCSP web
  dashboard in your browser
- **Configure**: Set your DCSP server URL

## Commands
- `DCSP: Repair Current File`
- `DCSP: Open Dashboard`
- `DCSP: Configure Server URL`

## Configuration
- `dcsp.serverUrl`: DCSP server URL
  (default: http://localhost:8000)
- `dcsp.apiKey`: Optional API key
- `dcsp.autoRepair`: Auto-repair on save
